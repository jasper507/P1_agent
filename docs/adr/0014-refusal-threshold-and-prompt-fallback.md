# 拒答阈值定在 0.55，和政策沾边的问题交给提示词兜底

评测里，政策里有的题，向量那一路的最高相似度最低是 0.569（「可以指定发顺丰吗」）；政策里没有的题，最高是 0.666（「买完就降价了，能退差价吗」）。两组分数有重叠，一个阈值分不干净。

我们决定：

- 阈值定在 0.55。51 道政策里有的题一道都不误拒；12 道政策里没有的题拦下 6 道：今天天气、会员积分、实体店、改手机号、分期付款、人工客服几点上班。比有政策的题里最低的 0.569 留了一点余量。
- 没拦下的 6 道都和政策沾边：退差价像退款，预约周末送货像配送时长，两张优惠券叠加像优惠券分摊，另外还有货到付款、补货、注销账号。系统提示加一句：查到的条款没有回答用户问的事时，也照实说政策里没有相关规定，建议联系人工客服，不要拿意思相近的条款推断。
- 分工是：闸门拦明显无关的问题，模型拦沾边的问题。

## Considered Options

- **0.60**：能多拦 5 道，但会误拒 3 道政策里有的题。答得出的问题被转给人工，比把沾边的条款交给模型（还有提示词兜底）更伤。
- **卡在 0.569 下面一点（比如 0.565）**：多拦 2 道，但这等于照着这批题的最低分画线，换一批说法就会误拒。
- **不设闸门，全交给模型判断**：天气、积分这种毫不相干的问题，也会塞给模型 4 段条款，全靠提示词守住。
- **用重排模型的分数拒答**：见 ADR 0013，评测说不够用了再加。

## Consequences

- 沾边的问题能不能拒掉，要看模型守不守提示词。检索评测测不出这一点，要到第 7 步评整个回答时才量得到。
- 阈值是在同一套题上定的，没有留出单独的题来验证。「人工客服几点上班」是 0.547，离阈值只差一点。
- 政策或者向量模型变了，要重跑评测，重新定阈值。
