# 订单状态筛选暂时放在 agent 端

商城的订单列表接口只能翻页（每页 20 张、最新的在前），不能按状态筛选，而商城仓库目前只读不改。我们决定：agent 一页页取、边取边筛，最多翻 5 页（最近 100 张），最多返回 10 张，并用 `has_more` 告诉模型后面还有没有。这样不改商城代码，也能先支持「我有哪些待付款订单」。

## Consequences

- 最近 100 张以前的订单，按状态查不到。
- 要找的状态很少见时，要多翻几页，多几次往返。
- 商城接口加上 `?status=` 参数以后，这条决定会被新的 ADR 取代，筛选交给数据库。改商城代码之前要先征得用户同意。
