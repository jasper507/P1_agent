P1 项目面经

按你简历上的每一句话出题：面试官看到一句描述，就会顺着问「为什么这么做、不这么做会怎样、出了问题怎么办」。这一份只管项目，八股以后再加。

必问 几乎每场都会问 高频 简历写了就容易被问 深挖 前一题答得好才会追到这里 陷阱 容易答错或说过头
怎么用这一页
  1. 先别点开要点。看着题目，自己出声答一遍（最好掐表：一般一题 1–2 分钟）。
  2. 再点开「回答要点」对一下，漏了的就是要补的。紫色框是常见的说错的地方。
  3. 答顺了就点右边的「会了」，下次可以只看「没会的」。这个标记只存在你这台设备的浏览器里。
  4. 回答套路：场景 → 问题 → 我的做法 → 为什么不用别的 → 数据或证据 → 还没解决的。最后一句「还没解决的」很加分，说明你知道边界。

之后的提问方式（你选一种或混着来）

1. 真实面试我当面试官，一次问一题，你答完我按你的回答往下追问三四层，最后给你打分、指出漏了什么。最接近真面试，推荐先用这个。
2. 压力面我专门挑刺：「这不就是调个 API 吗」「你这个数据样本太小了吧」。练的是被质疑时不慌、能用证据回应。
3. 场景题「如果有 10 万用户同时用客服怎么办」「如果政策每天都改呢」。没有标准答案，练的是现场设计。
4. 画图讲流程我说一个流程（比如确认取消、秒杀下单），你按顺序口述每一步谁调谁、哪里会失败。练的是讲清楚。
5. 快问快答一连串短问题，每题 30 秒内答。比如「阈值多少」「为什么 404 不是 403」。练反应和细节记忆。
6. 讲给外行听假装我是 HR 或产品经理，你用不带术语的话讲项目。练的是开场两分钟的介绍。
