# Mission: 把 P1 客服 agent 讲成面试里的逻辑闭环

## Why
同时投 AI 应用（agent）岗和 Python 后端岗。简历上写两个强相关的项目：电商系统（项目一），和接在它上面的客服导购 agent（项目二）。面试时要能从业务出发，把每个设计决定的「为什么这样做、代价是什么、怎么改进」讲成闭环，扛得住追问。

## Success looks like
- 不看资料，90 秒讲清楚一次「我的订单」请求从浏览器到商城再回来的完整链路，以及每一步失败时用户看到什么
- 被追问「为什么不用服务账号」「为什么不让前端传 user_id」时，能说出替代方案和取舍
- 每一步做完，都能答出该步学习指南里的面试题
- 项目全部做完后，能扛住一轮完整的模拟面试

## Constraints
- 项目面向面试，难度别太高；代码由 Claude 写和跑，我负责 review 和理解
- 讲解以业务角度为主，只保留必要的核心代码
- 学习文档用本地文件，不用 Claude Docs
- 模拟面试放到项目全部做完以后

## Out of scope
- 多 agent 协作和 MCP：不做，只需要讲清楚为什么不做
- 框架源码级的细节（Django、DRF、httpx 的内部实现）
