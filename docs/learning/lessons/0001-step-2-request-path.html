P1 客服 agent · 第 1 课 · 对应第 2 步

一次请求的旅程：谁拦住，用户看到什么

这节课只练一件事：不看资料，90 秒讲清楚「我有哪些订单？」这句话从浏览器到商城再回来，经过哪几道关卡，以及任何一关失败时用户看到什么。面试官问「如果……会怎样」，考的就是这个。

六道关卡

先记住顺序。前两道在进入 agent 循环之前，后四道在循环里面。

#关卡谁负责挡住什么
1看格式agent 入口没带 cookie、格式不对、夹带分号或换行的值
2认人Django /api/auth/me/过期或伪造的会话
3选工具模型只能从两个只读工具里选，没有别的能力
4验参数Pydantic 参数模型多余字段（比如 user_id）、非法状态、非 UUID 订单号
5判权限Django 订单接口别人的订单，一律 404
6做减法agent 工具收件人姓名、电话、详细地址，不发给模型

错误去哪儿的规律：第 1、2 关失败，直接返回 HTTP 401 或 502，因为模型帮不上忙。第 3 关以后预料之中的失败，写成文字交给模型，让它改正或如实告诉用户。代码 bug 不捕获，返回 500。
