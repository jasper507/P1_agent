同一段对话里的两条消息

这节课只练一件事：不看资料，90 秒讲清楚一条消息进到一段对话里，要过哪几道关，以及两条消息撞在一起、跑到一半出错、隔了很久才回来时，系统怎么保证历史不乱。

四道关

每条消息都按这个顺序走。第 1 关管「同一时间只有一条」，第 2 关管「只有主人能读」，第 3、4 关管「历史里没有半截」。

#关怎么做挡住什么
1加锁SET 锁 token NX EX 120同一段对话同时跑两轮；拿不到锁返回 409
2认主人读出对话，比对用户 id别人的、过期的、不存在的对话，一律 404
3限时跑一轮最多 90 秒，比锁短锁在一轮跑完前过期；超时返回 504
4整轮存跑完才存，只留最近 10 轮半截的工具调用；无限变长的历史

释放锁的规律：不管哪一关失败，锁都在 finally 里释放；释放时只删 token 对得上的那把，「比较再删除」是原子的。进程崩了来不及释放，锁 120 秒后自己过期。
