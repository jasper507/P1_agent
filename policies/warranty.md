# 保修政策

本文是示例商城的虚构售后政策，只用于演示客服 agent，不对应任何真实公司。

## 1. 保修范围和期限

### 1.1 数码配件

耳机、充电宝、数据线等数码配件，自签收之日起保修一年。保修期内出现非人为的功能故障，免费维修；修不好的，换一个同型号的新品。

### 1.2 服装鞋包

服装鞋包不提供保修。签收后三十天内发现的质量问题，按《退换货政策》第 3 节处理。

### 1.3 保修期怎么算

保修期从签收之日起算，以物流签收记录为准。维修或更换后，剩余保修期不重新计算；剩下不到三个月的，延长到三个月。

## 2. 不在保修范围内的情况

### 2.1 人为损坏

摔落、进水、挤压、私自拆修等人为原因造成的损坏，不在免费保修范围内，可以付费维修，费用由客服报价、买家确认后再修。

### 2.2 正常损耗

外壳磨损、电池容量随着使用自然下降等正常损耗，不属于故障。

## 3. 保修流程

### 3.1 如何申请保修

在「我的订单」里找到对应订单，点「申请售后」，选择「保修」，描述故障并上传照片或视频。

### 3.2 寄修的运费

审核通过后把商品寄回。保修期内的免费维修，往返运费由本店承担；付费维修的，往返运费由买家承担。

### 3.3 维修时长

本店收到商品后七个工作日内修好寄回；需要换新品的，三个工作日内寄出。

### 3.4 没有购买记录

不是在本店买的商品，或者拿不出订单记录的，不提供保修。
