# 退换货政策

本文是示例商城的虚构售后政策，只用于演示客服 agent，不对应任何真实公司。

## 1. 七天无理由退货

### 1.1 适用条件

自签收之日起七天内（含签收当天），商品保持原样、吊牌和包装完好、不影响二次销售的，可以申请七天无理由退货，不需要说明理由。

### 1.2 不支持无理由退货的商品

以下商品不支持七天无理由退货：定制商品，比如刻字、印照片的商品；已拆封的贴身衣物，比如内衣、袜子、泳衣；已拆封或已激活的数码配件，比如耳机、充电宝；购买时页面已注明「不支持无理由退货」的商品。这些商品有质量问题时，仍然可以按第 3 节办理。

### 1.3 无理由退货的运费

无理由退货的寄回运费由买家承担。下单时买了运费险的，按《运费政策》3.4 理赔。

## 2. 换货

### 2.1 换尺码和颜色

服装鞋包自签收之日起十五天内，可以换同款商品的其他尺码或颜色，每张订单限换一次。换货商品要保持原样、吊牌完好。想换的尺码或颜色没货时，改为退货处理。

### 2.2 换货的运费

因为尺码不合适等个人原因换货的，寄回运费由买家承担，本店寄出新商品的运费由本店承担。

## 3. 质量问题退换

### 3.1 质量问题的认定

商品有破损、开线、严重褪色、功能故障，或者和商品页面的描述明显不符的，属于质量问题。申请时需要上传照片或视频作为凭证。

### 3.2 质量问题的处理时限

自签收之日起三十天内发现质量问题的，可以选择退货、换货或维修。超过三十天的，数码配件按《保修政策》处理，服装鞋包不再受理。

### 3.3 质量问题的运费

因质量问题退换货的，往返运费都由本店承担。买家先垫付了寄回运费的，凭快递单在退款时一并退还，最多 20 元。

## 4. 退货流程

### 4.1 如何申请退换货

在「我的订单」里找到对应订单，点「申请售后」，选择退货或换货和原因，提交后客服会在一个工作日内审核。

### 4.2 寄回期限

审核通过后，要在七天内寄出商品并填写快递单号。超过七天没有寄出的，这次申请自动关闭，需要重新申请。

### 4.3 赠品

退货时要把赠品一起寄回。赠品已经用掉或丢失的，按赠品页面标注的价格从退款里扣除。
